# USDA Live Data Updater — Setup Guide

The dashboard (`remixed-8840b12b.html`) can **auto-refresh its prices from the four USDA AMS reports** without any chat round-trips or manual editing.

## How It Works

```
 ┌────────────────────────┐       ┌──────────────────┐       ┌────────────────────┐
 │ update_usda_data.py    │       │ data/latest.json │       │ dashboard.html     │
 │ (runs daily, 3:30 PM)  │──────▶│                  │──────▶│ loads JSON on      │
 │                        │ write │                  │ fetch │ page load, updates │
 │ ▼ downloads 4 PDFs     │       │                  │       │ values in-place    │
 │ ▼ parses prices        │       │                  │       │                    │
 │ ▼ writes JSON          │       │                  │       │ (wireframe intact) │
 └────────────────────────┘       └──────────────────┘       └────────────────────┘
```

Values it pulls:
- **LM_XB401** — Fresh 92-94%, 90%, 85%, 81%, 75%, 65%, 50% beef trim (national weighted avg)
- **LM_XB403** — Choice/Select cutout + key primals (Ribeye, Strip Loin, Chuck Roll, etc.)
- **LM_XB405** — 5-Day Rolling 100% Lean Items (Insides, Eye of Round, Flats, Striploin)
- **LM_PK602** — Pork primal cutout + 72%/42% trim + Belly sizes + Loin items

## One-Time Setup

### 1. Install Python (if not already)
Grab from https://www.python.org/downloads/ (any 3.9+ version).

### 2. Install dependencies
Open PowerShell or Command Prompt:

```powershell
python -m pip install pypdf requests
```

That's it. ~15 seconds.

## Automate — Run Daily at 3:30 PM Central

USDA AMS publishes these reports around **2 PM ET (1 PM CT)**. Run the script at **3:30 PM CT** to guarantee the latest data.

### Windows Task Scheduler Setup

1. Open **Task Scheduler** (Win+R → `taskschd.msc`)
2. **Create Basic Task** → name: `Jack Links USDA Data Refresh`
3. **Trigger**: Daily · 3:30 PM · Recur every 1 day
4. **Action**: Start a program
   - **Program/script**: `python`
   - **Arguments**: `"C:\Users\nagar\Downloads\Meat Inteligence Dashboard\update_usda_data.py"`
   - **Start in**: `C:\Users\nagar\Downloads\Meat Inteligence Dashboard`
5. **Finish** → right-click the task → **Properties** → check "Run whether user is logged on or not" → **OK**

Done. It will run every day without your involvement.

### Verify It Works

After the first scheduled run, check:
- `data/latest.json` exists and has a recent `fetched_at` timestamp
- The green "LIVE USDA DATA" pill shows in the dashboard's bottom-right

## What If a Report Changes Format?

USDA occasionally tweaks PDF layouts. The parser uses regex, so if parsing fails for one report, the others still work and the dashboard falls back to hardcoded values for the missing cut. Check `data/latest.json` — any failed report shows `"error": "..."` instead of prices. Ping me the error and I'll patch the parser.

## Troubleshooting

| Problem | Fix |
|---|---|
| `Missing dependencies` | `python -m pip install pypdf requests` |
| `cryptography` / Rust / `Microsoft Visual C++ 14.0 required` error | You're on ARM64 Python. The script uses `pypdf` (pure Python) — it does NOT need `pdfplumber` or `cryptography`. If you installed `pdfplumber` earlier, skip it; just run the `pypdf requests` install above. |
| `data/latest.json` not created | Check internet access; ensure URLs aren't blocked |
| Dashboard shows old numbers | Hard-refresh browser (Ctrl+Shift+R); JSON is fetched with `no-store` but browsers cache aggressively |
| Green pill doesn't appear | Open browser DevTools console; look for `[USDA loader]` messages |
| Task Scheduler: "0x1" error | Verify the Python path. Run `where python` in CMD; paste that full path in "Program/script" |
